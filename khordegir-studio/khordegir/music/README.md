# Khordegir Studio — Offline Mood Music Library (`music/mood_1.mp3` .. `music/mood_8.mp3`)

All 8 mood stems (`mood_1.mp3` through `mood_8.mp3`) and their generator (`generate_moods.py`) are original, self-authored procedural compositions created offline via deterministic Python synthesis (`math`, `wave`, `struct`) and encoded with `ffmpeg` (`libmp3lame` / LGPL-compatible CLI tool).
